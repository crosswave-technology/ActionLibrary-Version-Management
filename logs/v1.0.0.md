### Change Summary

Release baseline. Under the Nexus v2.1 clean re-baseline (ruling R3, plan step A6) this scope's release history and tags are wiped and re-minted at `v1.0.0` through the repaired pipeline. `Generate-Changelog` rebuilds `CHANGELOG.md` wholesale from `logs/*.md`, so this fragment is the whole of the recorded history from here on: it folds the pre-baseline narrative **and** the v2.1 wave changes into one entry.

Version promotion. This baseline makes the action's decision observable and stops three ways it could bump the wrong number.

#### Baseline changes

- **No `outputs:` block at all (MAD §2.3)** — the action wrote `promotion_type` to `$GITHUB_ENV` only, so the caller's `id: promote_version` yielded nothing. Nine outputs are now declared and populated, including `promotion_source` and `promotion_reason` — the promotion type **and why**. The `$GITHUB_ENV` write is retained, so existing consumers are unaffected.
- **E-13(a) label word-split** — labels were read unquoted and iterated with `for label in $labels`, so the label `Major refactor` produced the token `Major` and forced a major bump, while the semver gate matches labels exactly and never saw it. Matching is now exact.
- **E-13(b) last match wins** — the match loop had no `break`, so the last matching marker decided the bump rather than the most significant.
- **E-13(c) injection** — `head_commit.message` no longer reaches a `run:` body by interpolation.
- **E-12** — `action.yml` 197 mixed-ending lines → 344 lines, LF.
